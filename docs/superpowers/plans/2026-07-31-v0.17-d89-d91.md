# v0.17 (D89–D91) 구현 계획 — 무효 산출을 쓰지 않는다

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `config.toml`에 무효 TOML을 기입하는 경로를 닫고, 그 이탈을 감지·문면이 정확히
말하게 한다.

**Architecture:** 표준 TOML 파서를 **검증 전용**으로 들여 산출물이 파스되지 않으면 무변경으로
이탈하는 게이트를 install 경로에 둔다(D89). 점 표기 `env.*`를 env 서브테이블 정의로 인정해
헤더 중복 append를 막고, 표식을 쓸 자리가 없으면 사유와 함께 무변경으로 이탈한다(D90).
`doctor [20]`이 등록물의 도구 목록 부족을 알린다(D91). **공유 판정의 의미는 바꾸지 않는다** —
판독 결과에 정보를 더할 뿐이며 소유·표식·이상 판정은 불변이다.

**Tech Stack:** Go 1.26.5 · `github.com/pelletier/go-toml/v2`(신규, 검증 전용) ·
표준 `testing`(퍼즈 포함) · 외부 테스트 프레임워크 없음.

**스펙:** `docs/context-router-design-v0.17-ko.md` (커밋 `7e73397`)
**BASE:** `7e73397` — 각 태스크 리뷰의 diff 기준. `HEAD~1`을 쓰지 말 것.

## Global Constraints

- **파일 출력**: UTF-8(BOM 없음)·LF. 판정 지점은 **커밋 blob**이다.
- **테스트 실행**: `go test -p 1` 필수. 대상은 항상 `-run`으로 좁힌다. 전체 스위트 무제한
  실행 금지(메모리 캡 규칙).
- **커밋**: `git add -A` 금지 — 파일을 명시한다. 트레일러
  `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.
- **머지·태그·푸시는 사용자 명시 승인**이 있어야 한다. 태스크는 커밋까지만 한다.
- **임시 프로브는 반드시 지운다.** 저장소 안에 남기지 않는다.
- **주석 언어**: 한국어. 기존 파일의 주석 밀도·문체를 따른다("무엇"이 아니라 "왜").
- **줄 번호 인용 금지**: 주석·문서에서 `file.go:123` 형태로 코드를 가리키지 않는다. 심볼
  이름으로 가리킨다(이 릴리스가 만지는 파일 전체에 적용).
- **로컬 red 9건은 기준선**이다(`internal/exec`의 `powershell` 레그, 호스트 실행 정책).
  이 계획의 어떤 태스크도 그것을 고치지 않는다. `internal/cli`만 본다.
- **판정 불변**: `TestCodexEscapedManagedKey`의 전 픽스처와 install·uninstall 기존 테스트의
  판정은 이 릴리스 전후로 같아야 한다. 하나라도 바뀌면 범위를 넘은 것이다.
- **멱등**: 이 계획이 더하는 **모든 install 픽스처**에 `install(install(x)) == install(x)`를
  건다(스펙 §2.2). D84의 단일 백업 슬롯은 2회차가 무변경이라는 전제 위에 서 있고, 그 전제가
  깨지면 재실행이 원본을 잃는다. 무변경으로 이탈하는 픽스처는 자명하게 만족하므로 면제한다.
- **테스트 헬퍼**: Task 1이 만드는 `isolateCodexHome` · `writeCodexConfig` · `doctorOut`만
  쓴다. 같은 일을 하는 헬퍼를 새로 만들지 않는다. `runDoctor`의 인자는 여섯이며
  (`ctx, w, storeRoot, projectRoot, version, fix`) 그 순서는 `doctorOut` 안에만 둔다.

func TestCodexTOMLParsesMesh(t *testing.T) {
	cases := []struct {
		name  string
		src   string
		valid bool // true면 파스된다(게이트가 못 잡는다)

		{"같은 테이블 헤더 두 번", "[a]\nx = 1\n\n[a]\ny = 2\n", false},
		{"같은 테이블 안 키 두 번", "[a]\nx = 1\nx = 2\n", false},
		{"점 표기 같은 키 두 번", "[a]\nenv.FOO = \"1\"\nenv.FOO = \"2\"\n", false},
		{"같은 인라인 테이블 키 두 번", "[a]\nenv = { K = \"1\", K = \"2\" }\n", false},

// tomlDottedEnvKey — 원문 LHS가 `env.<둘째 마디>` 점 경로인가(D90). head는 첫 마디가 env일 때
// "env", 아니면 ""다. rest는 마디가 정확히 둘일 때 둘째 마디의 따옴표를 벗긴 이름이고, 마디가
// 셋 이상이면 ""다 — 그 형태도 env 서브테이블을 정의하지만 표식 자리는 아니다.
//
// **입력은 정규화 라인이 아니다.** stripLine은 따옴표 안 공백까지 지우므로 그 결과에 걸면
// `"e n v".CTR_MANAGED`가 env로 읽히고, 타인 테이블에 우리 표식이 선다. 문자열 밖 공백만
// 무시한 원문 LHS를 받는다.
func tomlDottedEnvKey(s string) (head, rest string) {
	lhs := s
	if i := tomlTopLevelEq(s); i >= 0 {
		lhs = s[:i]
	} else {
		return "", ""
	}
	segs := tomlSplitDotted(lhs)
	if len(segs) < 2 || strings.Trim(segs[0], `"'`) != "env" {
		return "", ""
	}
	if strings.Contains(segs[0], `\`) {
		return "", "" // 이스케이프 마디는 이 릴리스가 다루지 않는다(D93)
	}
	if len(segs) != 2 {
		return "env", ""
	}
	return "env", strings.Trim(segs[1], `"'`)
}

// tomlSplitDotted — LHS를 **따옴표 밖의 '.'**에서 마디로 가른다. 따옴표 안의 '.'는 이름의
// 일부이므로 단일 키 "env.FOO"가 점 경로로 오인되지 않는다. 각 마디의 앞뒤 공백은 지운다.
func tomlSplitDotted(s string) []string {
	var out []string
	start := 0
	for i := 0; i < len(s); {
		switch s[i] {
		case '"':
			i += basicStringLen(s[i:])
		case '\'':
			i += literalStringLen(s[i:])
		case '.':
			out = append(out, strings.TrimSpace(s[start:i]))
			i++
			start = i
		default:
			i++
		}
	}
	return append(out, strings.TrimSpace(s[start:]))
}

// tomlTopLevelEq — 따옴표 밖 첫 '='의 위치(없으면 -1). LHS를 자르는 데만 쓴다.
func tomlTopLevelEq(s string) int {
	for i := 0; i < len(s); {
		switch s[i] {
		case '"':
			i += basicStringLen(s[i:])
		case '\'':
			i += literalStringLen(s[i:])
		case '=':
			return i
		default:
			i++
		}
	}
	return -1
}
