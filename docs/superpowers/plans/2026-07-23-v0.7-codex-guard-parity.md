**Goal:** Codex CLI 세션(cx:)에 Claude 채널과 동등한 단일파일 덤프
가드(PreToolUse deny)를 이식하고, deny 안내(ctr_search/ctr_fetch)를
실효화하는 ctr MCP 자동 등록(config.toml 관리 블록)을 `hook install
--codex`에 결합한다.

**Architecture:** 스펙 = `docs/context-router-design-v0.7-ko.md`(SHIP,
a13d676) — 이 문서가 유일 계약이며 충돌 시 스펙이 이긴다. 가드는 기존
공유 dispatch(hook.go:153)를 그대로 쓰되 host를 Run→dispatch→guardBash로
명시 스레딩하고, **호스트×GOOS 단독 게이트**(cx:+Windows=PS 게이트
psDumpArg+psAbsPath / 그 외=bash 게이트 bashDumpArg+dumpAbsPath —
게이트는 술어+경로해석 묶음, 직렬·혼합 금지)로 선택한다. 설치는
config.toml 관리 블록(`# BEGIN/END context-router`) 병합을 먼저 수행하고
**MCP 확정 시에만** hooks.json에 PreToolUse 그룹을 등록한다(설치 결합 —
"deny+안내 도구 부재" 봉쇄). D49(content.db 파일 축 회수)는 설계만
스펙에 있고 **구현 태스크 없음**.

**Tech Stack:** Go(모듈 `github.com/wotjr1649/context-router`), stdlib만
(신규 의존 금지 — TOML 파서 도입 금지, 스펙 §0 D48), 기존 테스트 관례
(테이블 테스트·t.TempDir·`strings.Repeat` 대용량 픽스처).

  전체 스위트는 최종 태스크에서만 `go test ./... -p 1`.
- 파일 출력 UTF-8(no BOM)·LF. 커밋 전 `gofumpt -l .` 무출력 확인.

- 대용량 테스트 데이터는 whole-file 재작성 금지 — `strings.Repeat`/

```go
func TestGuardDumpPath(t *testing.T) {
	cases := []struct {
		name    string
		host    Host
		goos    string
		command string
		want    string
	}{
		{"① cx+win PS게이트: Get-Content 백슬래시", HostCodex, "windows", `Get-Content C:\ws\big.txt`, "C:/ws/big.txt"},
```

```go
// guardDumpPath — D47 호스트×GOOS 단독 게이트 선택(스펙 v0.7 §2). 게이트는 어휘 술어+
// 절대경로 해석이 묶인 완결 정책이라 직렬·혼합 금지: cx:+Windows는 PS 게이트(실측 §7 —
// Codex Windows exec는 raw PS 구문), 그 외(cx:+비Windows·cc: 전체)는 bash 게이트.
// 반대 방언 덤프는 miss=allow(fail-open by-design, 스펙 §2 셸 방언 한계).
func guardDumpPath(host Host, goos, command string) string {
	if host == HostCodex && goos == "windows" {
		return psAbsPath(goos, psDumpArg(command))
	}
	return dumpAbsPath(goos, bashDumpArg(command))
}
```
