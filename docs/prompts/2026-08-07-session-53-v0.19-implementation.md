### 3.4 ★★ 측정이 설계를 고친 다섯

1. **D98 정정.** "루트 `.mcp.json` 자리를 비워 두면 로컬 개발 설치본과 충돌하지 않는다"는

   그 루트 파일을 **선언된 `./plugin/mcp.json`보다 먼저 읽는다** `[실측]`. 원격 설치에는
   영향이 없다(그 파일이 없다).
2. **`plugin details`는 경로 문자열로 선언된 MCP 서버를 못 센다** — 런타임이 연결하는데도
   `MCP servers (0)`을 낸다 `[실측]`. 검증 단계로 쓰면 거짓 음성이다.
3. **미추적 파일은 배송되지 않는다.** 설치가 커밋된 내용에서 재료를 얻으므로, 커밋 전에는

4. **Codex 훅은 persisted trust 없이 돌지 않는다.** `codex --help`가
   `--dangerously-bypass-hook-trust`를 *"Run enabled hooks without requiring persisted
   hook trust"*로 적고 `[문서]`, 진짜 홈 프로브가 **빈 store**로 끝났다 — `SessionStart`조차

5. **`CTR_ENABLE`이 플러그인 경로에서 죽어 있었다.** 매니페스트가 `--enable ingest,net`을
