## 5. Standing protocols (delta only — rest as session-12 §5)

- **8.3 short-name portability trap (new):** CI Windows `t.TempDir()` =
  `C:\Users\RUNNER~1\...` — any lexical gate that rejects `~` (or non-ASCII)
  makes fixtures silently bypass the guarded path locally-green/CI-red. Fixture
  paths through such gates need `filepath.EvalSymlinks` normalization. Same class
  risk: Korean/Unicode local paths never exercise guardBash (allow-bias, by design).
- **`ctr_export_events`/`ctr_session_summary` session_id needs `cc:` prefix**
  (bare UUID returns empty — struck during smoke).
- **Host tool_response truncation ~30K observed** (with `persistedOutputPath`
  field) — shadow captures of huge Bash outputs store the truncated JSON; sizing
  expectations should assume ≤~30KB per Bash capture.
- **Write-tool byte corruption struck again** (space→NUL in escape-adjacent test
  content) — node-script assembly + byte-verify workaround held (memory rule
  confirmed effective; keep runtime assembly for all `\uXXXX`-adjacent authoring).
- **Plan-executor simulation in task reviews keeps paying:** T5 (shadow-append
  trigger existence) and T6 (T3 skip misread) were both caught only because
  reviewers independently re-derived what the brief's grep/anchor actually yields.
