## 5. Standing protocols

- **Stuck → collaborate**: implementer BLOCKED / 2–3 failed attempts / unclear fix → Codex rescue (design, root-cause); library facts → web / context7. No blind retry. (Project memory `stuck-protocol-codex-web`.)
- **Dual review**: integration (multi-commit) and final whole-branch reviews = subagent reviewer + **Codex `review --base <ref>`** in parallel → merge → fix. (Session 01 proof the two models cover each other's blind spots: Codex found userinfo credential leak, special-use SSRF, euc-kr charset; frontier model found snippet redaction bypass, worker race.)
- **SDD**: `superpowers:subagent-driven-development` — fresh subagent per task + task review (spec + quality) + fix→re-review. BASE from the ledger (never HEAD~1).
