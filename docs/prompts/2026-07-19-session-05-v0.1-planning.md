## 2. What was done

**Decisions agreed (design doc D14–D20; user picked per-question):**
- D14 event contract: free-form event_type + recommended vocabulary (§26 requires
  unknown-type preservation on export — closing producer side would be asymmetric);
  required event_type·summary, optional attributes/artifact_refs/related/supersedes;
  server-stamped identity (event_id UUIDv7 · session_id · ts · producer); caps
  summary ≤2KB / attributes ≤4KB / refs ≤16 / total ≤8KB; redaction at record time
  (ingest.Redact reuse + json.Valid recheck); tools **registered by default**.
- D15 storage: single event table + **immutable sessions meta table** (added in review
  round — producer misattribution + retention policy conflict) + JSON payload;
  artifact refs = canonical URI `artifact://<session-id>/sha256-<hash>` as **hint**
  (not GC root; dangling → `missing: true`); **event FTS included** (user overrode
  the "defer FTS" recommendation — ctr_search scope extension, summary-only indexing).
- D16 export: MCP = §26 camelCase JSON array + rowid cursor; JSONL = CLI
  `session export`; wire struct owned by new `internal/session` package.
- D17 retention: sweep engine at server start + **indefinite default** (opt-in
  `--retention-events`, ParseDuration); **per-session semantics** — sweep deletes only
  events of sessions that declared a policy (protects the other host's indefinite
  expectation); `.bak`/marker excluded; no auto_vacuum.
- D18 corruption: **fail-closed + manual CLI recovery** — Codex adversarial-review
  NO-SHIP killed the original auto-rename (recovery lock can't stop an already-open
  sibling writer fd → silent fork of the only copy; 3-file rename non-atomic).
  Final protocol: 2 lock files (session.lock shared lifetime non-blocking +
  session.init.lock exclusive create-only — no mode transitions), conservative
  quick_check verdict, recover CLI with `recover-pending` marker + rowid-preserving
  salvage loop + single-file publish + crash-resume (incl. healthy-DB+marker cleanup).
- D19 worker robustness (GOMEMLIMIT ~80% / RLIMIT_AS VA headroom / kill-reason
  suffixes) split to a **preceding v0.0.2 patch**; only ctr_fetch description
  sharpening stays in v0.1.
- D20 gates: inherit format, new-surface-only (G1–G9), "host-dependent nondeterministic
  checks are non-blocking from the start" rule, gate-11 (schema token budget) rebaseline.

**Verified facts collected by research agents (with sources, ctx-indexed):**
- MCP stdio has **no protocol-level session id** (go-sdk v1.6.1 `ServerSession.ID()`
  is Streamable-HTTP-only — confirmed in module cache source) ⇒ process = session,
  server issues UUIDv7 (google/uuid v1.6.0 already in module graph, indirect→direct).
- Claude Code `cleanupPeriodDays` 30-day default backlash (GitHub #64999/#59248) —
  ground for indefinite default retention.
- SQLite: single events table + JSON payload is the append-only norm; FTS5 external
  content 'rebuild' makes deferred FTS cheap (kept as design note); auto_vacuum
  must be decided at creation and isn't worth it for append-mostly logs.
- modernc.org/sqlite has **no `.recover` API** ⇒ salvage = SQL-level rowid-skip loop.
