6. **Standing protocols** (유지 + 이번 세션 실증)

   - **계획이 축자로 지정한 코드에도 공백이 있다** — 이번 세션의 plan_conflict 넷이 전부 그
     부류였고, 넷 다 저장소에 이미 선례가 있거나(같은 파일의 기존 관용구) 제품 코드와
     어긋나 있었다. **계획을 따르되 그것이 무엇을 검증하는지 매번 확인하라.**
   - **크로스모델이 서브 리뷰어가 못 보는 것을 본다** — Codex가 Task 5의 `FailedFiles`
     공백과 Task 6의 perf 축 공허함을 냈다. 둘 다 **diff 밖의 코드와 대조해야** 보이는
     것이었고, diff만 보는 리뷰로는 구조적으로 안 잡힌다.
   - **Codex 회수 타이밍** — diff가 커지면 Codex가 리뷰 서브보다 늦게 끝난다(11KB는 먼저,
     25KB는 나중). 리뷰 서브를 지연시키면 체크포인트가 직렬화되므로, **미완이면
     `codex_available=false`로 확정하고 컨트롤러가 뒤늦은 결과를 병합 서브로 소비**한다.
     최종 리뷰 패스는 세 번 읽어도 노이즈만 있었다(회수 실패 2/8).
   - **편집 도구 이스케이프 오염이 양방향으로 실재한다** — 이번 세션에서 **네 번**.
     `\uFEFF` 여섯 글자가 실제 U+FEFF 바이트로, 그리고 한국어 주석이 리터럴 `\uXXXX`
     텍스트로. **한 번은 컴파일도 테스트도 통과하는 무증상 오염이었고 바이트 검사만이
     잡았다.** 모든 dispatch에 바이트 검사를 요구하고 그 출력을 보고에 남기게 하라.
     autocrlf 호스트에서는 **작업 트리가 아니라 커밋 blob**이 정확한 판정 지점이다.
   - **테스트가 제품 환경을 재현하지 않으면 결과가 세션 의존이 된다** — 실행 헬퍼가
     `cmd.Env`를 nil로 두면 자식이 호스트 환경 전체를 상속하고, 결과가 "테스트를 띄운 세션이
     무엇을 상속했는가"의 함수가 된다. 닫으면 로컬이 red가 될 수 있고 **그것이 정직한 상태다**.
   - **전제를 검증 없이 dispatch에 넣지 마라** — 컨트롤러가 "이 호스트 5.1은 `.ps1`을 못
     돌린다"를 조건으로 넘겼는데 절반만 맞았다(환경 변수 상속 여부에 달려 있었다). 구현자가
     실측으로 반박하고 제안된 Skip 가드가 통과하던 레그를 4 SKIP으로 만든다는 것까지 보였다.
   - 유지: `go test -p 1` / 메모리 캡 / `gofumpt -l .` 무출력 / **`git add -A` 금지** /
     BASE를 원장에 기록 / 스펙 승 / 보안 서술 최소화 + 중립 프레이밍 + JSON findings
     (`docs/codex-secure-review.md`) / 리뷰 체크포인트 = 서브 + Codex 1패스, 재리뷰는 서브
     단독 / CI 3-OS가 unix·5.1 실검증 권위 / **머지·태그는 사용자 명시 승인** /
     `docs/superpowers/plans/`는 immutable, 정정은 설계서에.
