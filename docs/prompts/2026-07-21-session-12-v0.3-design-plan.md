## 5. Standing protocols (delta only — rest as session-11 §5)

- **Edit/Write `\uXXXX` trap struck TWICE this session** (design doc 1 NUL,
  plan doc 3 NULs — the latter caught by Codex, not by me). Hardened rule:
  **never put escape-sequence text directly in any authored file**; write it
  as runtime assembly (`"\\"+"u0000"`) or describe in prose, and byte-verify
  (`control bytes==0`) after EVERY Write/Edit that touches escape-adjacent
  content. Neutralize+rewrite via scratch node script (`denul.js` pattern) if
  struck.
- **Dual review remains non-redundant at both checkpoints:** design (install
  trap found by both; provenance/upgrade/double-count Codex-only; shell-set
  contradiction subagent-first) and plan (path semantics/`git add -A`/NUL
  bytes Codex-only; [14] no-store conflict/(b) non-inversion subagent-only).
  Keep subagent+Codex parallel, merge before fixing, downgrade with evidence
  when warranted (provenance P1→documented limitation).
- **Plan reviews must simulate the executor**: "구현자는 자기 태스크 문면만
  본다"를 리뷰 프롬프트에 명시하니 anchor-miss(silent skip 유발)와 미열거
  파급(11 call sites)이 정확히 걸렸다. 재사용할 것.
- ctxscribe ctx_execute 출력이 5KB 넘으면 자동 인덱싱되어 제목만 온다 —
