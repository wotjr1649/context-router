7. **Standing protocols** (유지 + 이번 세션 실증)

   - **감시선은 "추가했다"가 아니라 "실제로 물리는가"로 판정한다.** 이번 세션이 세 번 실증했다 —
     UTC 골든이 러너 타임존에서 무력, 새 잡이 자기 전제 미검증, 셸 게이트가 fail-open.
     **테스트·게이트를 추가하는 태스크는 그것이 깨지는 것을 한 번 보여주는 증거를 요구하라.**
   - **리뷰어 제안도 검증 대상이다.** Task 1에서 리뷰어의 fix 제안이 원리상 듣지 않는 것이었고
     컨트롤러가 교정했다. session-37의 "서브에이전트 보고는 검증 대상" 규율이 리뷰 제안까지
     확장된다.
   - **문서에 적힌 수치·식별자는 재현하기 전까지 기대값이다.** errcheck 13 vs 4가 두 세션에 걸쳐
     뒤집힌 원인은 도구 기본 상한이었다. 수치를 기록할 때 **어떤 옵션으로 얻었는지**를 함께 적어라.
   - **컨트롤러는 fix를 직접 하지 않는다**(전부 서브 위임, 컨트롤러 컨텍스트는 조율용으로 유지).
     이번에 컨트롤러가 직접 한 것은 원장·핸드오프 기록과 리뷰어가 diff만으로 확인 못 한 항목의
     저비용 확인(트레일러·gofumpt·인코딩)뿐이다.
   - **크로스모델 리뷰 = 중립 프레이밍 + JSON findings**(`docs/codex-secure-review.md`). 유지.
