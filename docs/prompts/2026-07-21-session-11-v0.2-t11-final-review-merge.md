## 5. Standing protocols (delta only — rest as session-10 §5)

- **Cross-model finals are non-redundant:** subagent said Ready-to-merge while
  Codex found 2 real P1s (and Codex missed M1). Keep the dual final review.
- **Edit-tool `\uXXXX` trap:** writing a literal `U+0000`-style sequence
  through Edit/Write params gets JSON-decoded into a REAL control byte in the
  file (shadow.go got NUL-corrupted mid-session; repaired via a node script
  assembling bytes by char code). When source must contain such text, build
  the needle programmatically or verify bytes after edit. Non-`\u` backslash
  sequences (e.g. `'\''`) pass through fine.
- **`claude -p` headless = real-host smoke harness:** `--output-format json`
  gives session_id for store cross-checks; `--allowedTools 'Bash(x:*) ...'` +
  `--model haiku` keeps it cheap/safe. Deny-listed commands (e.g. `python -c`)
  are blocked in child sessions too — pick probe commands accordingly (`seq`).
- **Hooks hot-load into running sessions** (settings written by `hook install`
  took effect immediately in the installing session) — but a capture hook added
  by hand-editing settings did NOT fire in the running session (approval gate);
  fresh sessions honor the full file. Plan measurements around fresh sessions.
